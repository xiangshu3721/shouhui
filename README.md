# 找回主体性 · V0.2

一个帮助你减少内耗、看清边界、找回主动权的小练习。

线上地址：https://xiangshu3721.github.io/shouhui/

- 纯静态 HTML / CSS / JS：无后端、无 AI、无登录、无需 API Key
- 数据只存在本机 localStorage（键 `shouhui.v1`，带 `schema` 版本号；昵称与其它测评共用 `rk.v1.nickname`）
- 5 个视图：首页 / 16 题测评 / 测评结果 / 今日卡牌 / 我的觉察
- 可加到主屏（manifest + 简单 service worker；资源带 `?v=` 版本号，升级时同步改 `sw.js` 里的 `VERSION`）

## 视觉

V0.2 起为柔和水彩疗愈风（雾山湖星）。卡面插画为本地 SVG（`img/cards/`、`img/hero/`），无外链。

## 改字

所有文案（题目、选项、维度说明、练习方向、下周提醒、24 张卡、按钮）都在 `js/content.js`，
每条标了 `src: "user"`（用户原文）或 `src: "added"`（补写）。

## 规则速记

- 维度得分 =（4 题平均分 − 1）÷ 4 × 100，取整；同分按 评价牵引 → 边界混淆 → 控制期待 → 行动退缩 排
- 选卡：同一张卡 7 天内不重复（同一维度 6 张都出现过时，取最久之前那张）
- 「随便给我一张」：做过测评按 60% 第一维度 / 30% 第二维度 / 10% 其他两维；没做过测评四维均匀
- 7 天小结：从首次使用起满 7 天后，统计最近 7 天完成的觉察
